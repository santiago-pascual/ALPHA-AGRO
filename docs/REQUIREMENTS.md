# Proposed requirements

## MVP

- Select one supported Argentine region and one crop. Make the pilot crop and coverage clear on the first screen.
- Use an interactive map to select a supported location and resolve it to the scientific grid or documented region. Provide a mobile-friendly region or location control alongside the map.
- Show the latest available observed conditions with observation date, source, units, grid resolution, and coverage status. Handle missing and stale inputs explicitly.
- Let the user select from supported environmental variables. Present a real historical trend with effect size, uncertainty, significance when justified, and a geographic comparison. Show at least one supported cross-variable relationship with its limitations.
- Define one measurable hydrological target and evaluate simple baselines on historical out-of-sample data. Expose a prediction only if evidence supports it. A historical replay is acceptable if explicitly dated and distinguished from a current prediction.
- Reproduce the analysis from documented inputs and steps. Ship a working demo and publish the methodology and limitations alongside the submission.

## Optional extensions

Additional crops and regions, planting date or growth stage, field boundaries, longer horizons, live updates, calibrated model probabilities, and richer maps. Prioritize based on data coverage and validation. Keep the core demo usable without entering private farm details.
