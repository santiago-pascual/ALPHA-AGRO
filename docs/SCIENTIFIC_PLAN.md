# Proposed scientific plan

Use the [scientific research charter](SCIENTIFIC_RESEARCH_CHARTER.md) to set priorities. The MVP starts by validating one feasible prediction horizon. Assess the data support for 7, 14, and 28 days, evaluate each feasible horizon against the baselines, and document any horizon that could not be evaluated.

## Historical trend and relationships

1. After opening, select one Argentine region and one crop based on coverage and agricultural relevance. Predefine analysis windows, a seasonal grouping, a small set of regions or grid cells, and a primary outcome. Keep the inclusion rules independent of the results.
2. Inventory product versions, units, quality flags, coordinates, reference grids, coverage and observation/release times. Quantify missingness by period and location. Align windows and make precipitation totals, moisture states, temperature averages, and vegetation composites comparable without mixing meanings. Compare on defensible common spatial support and retain the native footprint for interpretation.
3. Plot historical series and coverage. Inspect seasonality, anomalies, discontinuities, and autocorrelation. Use season-specific or seasonal tests where appropriate. Use Mann–Kendall and Sen's slope where the record and assumptions support them. Estimate slope in physical units per decade or another documented interval and report sample counts, confidence intervals, direction, and statistical significance.
4. Account for serial dependence before interpreting significance. Consider a dependence-adjusted test or a suitable block bootstrap and check sensitivity to aggregation, window, or block length. Limit comparisons and control false discoveries where testing across many cells. With weak support, report descriptive results and the inference limitation.
5. Compare trend magnitudes and intervals across locations using comparable periods. Explore precipitation–soil moisture, temperature–moisture, and moisture–vegetation relationships using seasonally adjusted or detrended series and pre-specified lags where data support them. Report paired coverage and uncertainty, consider shared forcing or confounding, and avoid causal interpretation.

## Hydrological prediction experiment

1. Choose one observed or explicitly model-derived target and one feasible horizon after examining availability. A candidate target is occurrence of a low surface-moisture threshold during the next seven days, using a season-aware threshold defined on training data. Document units, label window, missing-label rules and why the target is meaningful. A continuous target is an option if event counts are insufficient.
2. Use an issue-time view of each input and track its actual publication lag. Exclude future observations, incomplete composites, centered filters, and delayed revisions that would have been unavailable at the issue time. Track dependence between the source for labels and predictors.
3. Separate older training, chronological validation and a final later held-out test. Use blocked or rolling-origin validation, and purge windows where forecast labels overlap a split boundary. Fit thresholds, climatologies, imputation, transforms and calibration using only eligible training and validation periods. Keep the holdout untouched until the final evaluation.
4. Compare seasonal climatology and persistence before testing an optional gradient-boosting model. For a binary target, report event counts, Brier score and skill against climatology, plus reliability and precision–recall if counts permit. For continuous targets, report MAE against both baselines and interval coverage if intervals are provided. Use time-blocked resampling for uncertainty when defensible and report metric limitations with small samples.
5. Calibrate probabilities using time-separated validation when supported and measure reliability on held-out data. Ship a historical replay if realistic data availability can be reproduced but live delivery cannot. If skill, calibration evidence, or input availability is insufficient, report the evaluation and withhold the forecast display. Keep crop damage outside the claim.
6. Where geographic coverage supports a spatial test, hold out blocks of locations and preserve chronological ordering within the evaluation. Choose blocks with spatial dependence and shared source footprints in mind. Report temporal skill and spatial transfer separately, including any limits on the locations the results represent.
